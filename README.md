GOLDEN KOI RAMEN — a giant golden koi bursting out of a ramen bowl on a wooden table: broth splashing in arcs, chopsticks flying, steam curling, warm restaurant light. Drawn in pure Python with the standard library only — no third-party packages, no downloaded images. Entry for make.fun's "Make the AI judge excited" bounty, $250 in USDC.

## Run it

```sh
python3 main.py
```

The program draws `entry.png` (1024x1024) deterministically — run it twice and the bytes are identical. It writes to `$MAKEFUN_OUTPUT_DIR/entry.png` when set, else `/output/entry.png`, else beside `main.py`.
